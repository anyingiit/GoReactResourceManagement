## 关于本项目

尽管名字里带着 Go 和 React，GoReactResourceManagement 从未存放过 Go 后端、React 前端或任何其他应用代码。它的全部历史只有一次提交——"chore: add open-source baseline"——提交信息本身说明它只是从 anyingiit/chefs-pick-oss-starter 添加了这个账号新建仓库时使用的标准社区文件（本 README、`LICENSE`、`CONTRIBUTING.md`、issue 模板以及 CI/dependabot 配置）。[`CHANGELOG.md`](CHANGELOG.md) 同样只记录了一条 "Initial project structure"，并且这个仓库现在已被归档。

这里没有任何资源管理应用程序，过去和现在都没有，也就无需构建、运行或撰写文档——只需要说明这个仓库到底是什么。

## 开始使用

### 前置条件

没有 Go 工具链、Node.js/npm 或任何其他构建依赖需要安装——仓库树中没有 `go.mod`、`package.json`，也没有任何形式的清单文件。只有当你想在本地保留这份脚手架的副本时，才需要一个 `git` 客户端。

### 安装

没有任何东西需要安装；这个仓库从来没有包含过 Go 模块或 React 软件包：

```sh
git clone https://github.com/anyingiit/GoReactResourceManagement.git
```

克隆后只会得到上面描述的脚手架，而不是一个可运行的应用程序。

## 使用方法

没有服务端可以启动，也没有前端可以构建。这个仓库是已归档的脚手架，不是一个 Go/React 资源管理系统——如果你是抱着找一个真实项目的期待来到这里，你要找的很可能是这个账号下的其他仓库。
